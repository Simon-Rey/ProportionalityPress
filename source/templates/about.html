About the Proportionality Press

The Proportionality Press is a website developed by Simon Rey as part of the project Fair Online Group Decision Making led by Jan Maly.

The website's source code is open-source and available in this GitHub repository.

The site is currently maintained by Jan Maly.

Data

The data presented on this website was collected via the Polis platform and is available as open-source in the Polis GitHub dataset.

The datasets shown here are processed versions of the original Polis data. For each article, all the comments are drawn from the original Polis dataset. We have removed all demographic statements (e.g., “I am over 50,” “I live in the city,” etc.) as they do not reflect participants' opinions.

For some datasets, the content of original press articles has been used to provide context for the discussion. Each referenced article is properly cited and linked.
